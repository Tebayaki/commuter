# 通勤路线提醒

程序按 `.env` 中配置的早晚时间，分别查询上班（家到公司）和下班（公司到家）的高德驾车路线。只有 B 路线预计比 A 路线更快时，才通过 Server 酱推送建议。

## 配置和运行

复制 `.env.example` 为 `.env`，并填写高德 Web 服务 Key、Server 酱 SendKey、家庭和公司坐标以及希望执行评估的时间：

```sh
cp .env.example .env
# 编辑 .env，填写你的配置

uv sync
uv run commuter
```

`.env` 中的 `WORK_TIME` 和 `HOME_TIME` 使用 `HH:MM` 格式；`WORK_DAY` 使用逗号分隔的数字表示星期，`1` 至 `7` 分别代表周一至周日。例如 `1,2,3,4,5` 表示周一至周五，`1,2,3,4,5,6` 表示周一至周六。两个上下班任务都会在 `WORK_DAY` 指定的日期执行。`HOME_POINT`、`WORK_POINT` 和四个途经点配置填写 `经度,纬度`，多个途经点用分号分隔。途经点可以留空，时区通过 `TIMEZONE` 配置。也可以直接设置同名系统环境变量，系统环境变量优先于 `.env`。

调度器会一直运行，请将进程部署在持续在线的设备或服务上。真实 `.env` 文件已加入 Git 忽略规则，请勿提交密钥或个人坐标。

如果高德路线查询或 Server 酱请求失败，程序会记录错误，不会发送路线查询失败的推送。
